# De Gouden Kurk

Statische websitepreview voor De Gouden Kurk aan het Raadhuisplein 6 in Rozenburg.

## Live

De preview is publiek via GitHub Pages:

**https://jalvdbroek-ship-it.github.io/de-gouden-kurk-site/**

De code staat in `jalvdbroek-ship-it/de-gouden-kurk-site`. Elke push naar `main` publiceert de website opnieuw via de workflow in `.github/workflows/pages.yml`.

## Lokaal bekijken

```bash
npm start
```

Open daarna `http://localhost:4173`.

## Controle

```bash
npm run check
npm test
```

## In deze versie

- Een eigen, responsive webshopinterface met warme wijn- en messingkleuren
- Echte productfoto's met bron- en licentieherleiding in het beeldcreditsvenster
- Zoeken, categoriefilters, sortering en een winkelmand
- Een volledige concept-checkout voor ophalen en lokaal bezorgen
- Een eenmalig, verfijnd schenkmoment in de hero, gekoppeld aan de leeftijdpoort
- Leeftijdvenster, formuliervalidatie en lokaal gehoste kaart en lettertypen
- Een expliciete previewstatus, zonder betalingen, bestellingen of opgeslagen persoonsgegevens

Zie `RESEARCH.md` voor de bronverantwoording, `REVIEW.md` voor de beoordeling en `DESIGN.md` voor de ontwerprichting.
